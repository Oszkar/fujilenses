FujiLenses Design System
Theme

Technical Clarity, refined.

The visual language for FujiLenses — an interactive lens explorer for the Fujifilm X-mount ecosystem. A calm, data-dense interface where the lens data is the only thing allowed to carry color. This page is the living reference: every token, type ramp, and component below is rendered live and reacts to the theme and accent controls.

Accent

One interactive accent, kept clear of every data hue. Pick one — the whole page updates.

Indigo is the recommendation: it reads unmistakably as interactive chrome and sits far from Fujinon's sky-blue data color, so links and selection never get confused with the catalogue. Azure and Amber are shown for comparison — both gorgeous, but they collide with a maker hue. Graphite is the "colour-comes-only-from-data" extreme.

# Thypoch native X-mount investigation

Checked **2026-11-21**. Scope: the two requested Simera lenses and related released native Fujifilm X still-photo lenses. Finish variants are one model record. Adapted M-mount kits are not native X versions. Weights below are published nominal product weights, not reviewer measurements; sources do not explicitly state all cap/hood exclusions.

## Eureka 28mm F2.8 ASPH.

Added as `thypoch-28mm-f28-eureka`.

This is a real released native X model, separate from the M lens plus M-X adapter. [Official release of 2026-04-28](https://thypoch.com/en/newsroom/117) offers both native versions and an adapted kit, with immediate shipment. November 2025 was pre-order announcement; **2026** is the verified shipping year.

[Official mount-labelled specifications](https://thypoch.com/en/eureka/28mm) give X weight **154g**, manual focus, 28mm, F2.8, and **27mm** filter thread. The 133g M figure and generic 137g in the launch/B&H copy are not the X-table value. The weight is labelled product; cap exclusions are unstated. [Eureka manufacturer FAQ](https://thypoch.com/en/eureka) explicitly describes an aperture ring and native E27 filter interface. Manual focus implies no autofocus drive/linear motor. [Exact X B&H listing](https://www.bhphotovideo.com/c/product/1933790-REG/thypoch_tp_e28x_blk_eureka_28mm_f_2_8_lens.html/overview) explicitly lists no optical stabilization but uses the conflicting 137g weight; prefer the manufacturer's mount-labelled 154g.

[Dustin Abbott's native-X hands-on](https://dustinabbott.net/2026/08/thypoch-eureka-28mm-f2-8-x-mount-review/) confirms the rotating front-barrel aperture control is declicked and that the lens has no electronic contacts. His **161g** scale measurement of the Pearl White X sample is distinct from the manufacturer's **154g** nominal specification, which remains the stored value; his measurement's cap inclusion is unstated.

`weatherResistant: false` is supported by [Camera Decision's exact-X FAQ](https://cameradecision.com/lenses/faq/is-the-Thypoch-Eureka-28mm-F2.8-ASPH-X-a-Weather-sealed-lens), whose rendered page explicitly states that this X model is not weather sealed. **Provenance caveat:** this is secondary database evidence, not manufacturer confirmation or a firsthand sealing inspection. No manufacturer sealing statement was located. The value is accepted on that qualified basis, rather than inferred from silence in the official specification table.

## Scope exclusions

The [manufacturer product catalog](https://thypoch.com/en/product) lists Simera 21/50/75mm, Eureka 50mm and Ksana lenses without native X variants; adapted compatibility is insufficient for adding native-X records. Voyager 24–50mm is Sony E, and Simera-C is a cinema series in M/E. Recheck if native X releases are announced later.
